# 在现有本地存储中按空间隔离知识和采用回执

当前正式客户端已经使用 SQLite 和本地资料副本，#32 延续该持久化路线，不恢复历史方案中的 PostgreSQL、Neo4j 或对象存储部署。ADR 0002、0003 描述的是早期方案；它们不再决定当前客户端的持久化实现。

空间采用稳定身份，在同一数据库内分别保存完整知识事实、版本和采用回执，资料访问必须经过当前空间的资料记录。与每空间一个数据库相比，这让旧单图谱事实和既有采用回执能在一个事务中进入默认空间，并让最近使用的空间与空间集合一起持久保存；代价是每个正式读写入口都必须校验空间范围。

每次打开或切换空间还产生新的运行上下文版本。普通写入、文件复制、AI 请求、会话、草稿及采用同时绑定空间身份和该版本，拒绝切换后的迟到结果，包括切换回原空间的情况。模型连接和凭据继续由应用级配置管理，与空间内容分开保存。

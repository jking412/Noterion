# 使用可配置对象存储保存文件资料本体

Noterion 采用对象存储服务保存上传的 PDF、图片、文档和视频等文件本体，支持配置本地自部署服务或云端服务。PostgreSQL 保存正式资料信息、关联及稳定存储引用，Neo4j 不保存文件字节；文件不再以应用管理的普通本机目录或 PG 大对象作为本方案的主存储路线。

用户明确选择对象存储，且已确认单个视频 1–2 GB 是实际场景；保存副本主要用于查看，不要求系统外编辑或跟踪改名移动。该选择接受对象服务、读取接口及本体与 PG 记录一致性管理的工程成本，以取得独立的资料存储职责和本地/云端的配置空间。

当前工程推荐以 S3 兼容接口组织访问，由 Rust 本地核心处理对象读写和鉴权，使用稳定对象引用而非临时签名地址作为正式资料定位信息。具体产品、SDK 版本、真实 endpoint、云厂商及凭据仍按兼容性与实际环境确定；支持云端配置不等于已创建云资源或上传任何资料。

用户将查看方式委托代理选择。对象存储下的默认查看策略定为：PDF、图片及支持的视频优先在应用内只读查看，其他格式或播放失败提供外部打开；需本机路径时使用受控查看缓存。缓存不是正式文件来源，内置视频兼容、Range 读取和大文件资源使用需用实际样本验证，不承诺通用转码或全部编码支持。

# 容器排障速查

先记录现象，再按从外到内的顺序检查。不要一开始就重启，把现场信息保留下来。

## 1. 看当前状态

```sh
docker ps -a
docker inspect <容器名>
```

## 2. 看最近日志

```sh
docker logs --tail 100 <容器名>
```

把报错时间与一次具体操作对应起来，避免只截取一行信息。

## 3. 看宿主机资源

```sh
df -h
free -h
ps aux
```

## 4. 留下可复用的记录

- 现象：在什么时间、什么操作之后出现。
- 检查：执行了哪些命令，观察到什么。
- 判断：哪些证据支持当前推测。
- 结论：最终原因与修复步骤。

这份资料被 Docker、Linux 运维下的“容器排障”共用，也可从“查看容器日志”和独立的“排障记录模板”访问。

# 并发编程：从共享状态开始

## 先问三个问题

1. 哪些数据被多个线程共同访问？
2. 哪一组操作必须作为一个整体完成？
3. 完成之后，其他线程如何看到新的状态？

## 互斥保护

```java
synchronized (monitor) {
    updateSharedState();
}
```

保护的是一段关于共享数据的约定。参与这段约定的访问需要使用同一个同步机制。

## 线程池

记录任务来源、执行时间、队列长度和拒绝策略。复用线程解决了反复创建的开销，但任务积压仍然需要显式处理。

## CAS

```text
读取当前值
比较当前值是否仍等于预期值
相等则替换，否则重新判断
```

把失败重试、ABA 问题和对象生命周期一起考虑。这份资料可被多个并发相关知识点共用。

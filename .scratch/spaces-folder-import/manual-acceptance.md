## 1. 选择与文件清单

- [ ] 新建空间“文件夹验收 A”，进入“知识导入”，点击“选择文件夹”，在 Windows 原生窗口选中上面的 `folder-notes`。
- [ ] 显示 **6 份文件**，并显示“含子文件夹”。清单应完整包含下列相对路径；`ignore.csv` 不应出现在目标文件清单中。

| 相对路径 | 初始内容 / 预期 |
| --- | --- |
| `root.md` | 正常学习笔记 |
| `nested/notes.TXT` | 子目录、TXT 大写扩展名 |
| `other/notes.MD` | 另一子目录、MD 大写扩展名 |
| `bad.md` | 非 UTF-8 字节，应在读取时明确报错 |
| `empty.txt` | 空内容，应明确报错 |
| `large.TXT` | 超过 256 KiB，应明确报错，不截断 |

## 2. 逐份核对、编辑、采用与跳过

- [ ] 在 `root.md` 行点击“处理”。应只解析这一份文件；核对区显示其来源路径。
- [ ] 修改一个候选的名称或描述，再采用。应在当前空间图谱和搜索中找到修改后的知识；资料库应能找到并打开 `root.md` 的来源正文。
- [ ] 处理 `nested/notes.TXT`。若出现同名知识，选择“复用已有知识点”或明确更新相应知识点，再采用；不得因重名而静默覆盖。若模型识别了新知识，可以正常新建。
- [ ] 对 `other/notes.MD` 选择“跳过”。这一文件应计入“跳过”，不会新增其候选知识。已采用两份的成果应保留。
- [ ] 对照清单逐项检查状态与计数；“已保存 / 重复 / 跳过 / 失败 / 待处理 / 已取消”应与各行一致。不能只出现一句“完成”而丢失文件结果。

## 3. 错误、修复与重试

- [ ] 分别处理或重试 `bad.md`、`empty.txt`、`large.TXT`。每条失败都应对应具体路径：编码错误、内容为空、超过 256 KiB。其他已保存成果仍可使用。
- [ ] 用文本编辑器把 `bad.md` 保存为 UTF-8 正常笔记，给 `empty.txt` 加入笔记，把 `large.TXT` 缩小至 256 KiB 以内。示例内容可以是“Docker 容器使用独立的文件系统。”
- [ ] 不重新选目录，直接点击这些文件行的“重试”。应重新读取修复后的内容，进入核对；失败数相应减少，已保存数只有在明确采用后才增加。
- [ ] 解析中主动断开网络或使用不可用的模型连接，检查具体文件进入失败状态；恢复连接后可以重试。未采用的候选不得提前写入图谱。

## 4. 取消、保留与重复

- [ ] 至少保存一份后，对当前批次点击“取消批次”。已保存知识及来源资料必须仍可搜索、打开；未完成文件应清楚显示已取消。
- [ ] 重试已取消文件，并核对候选后采用。可继续处理；已保存文件不能被重复计作新成果。
- [ ] 重新选择同一个文件夹，再处理已经采用且内容未改的文件。应提示已经采用或重复，本次不重复写入知识，也不重复增加同一来源资料。
- [ ] 选择 `empty-folder`。应显示未找到 Markdown/TXT 文件，并仍可重新选择文件夹或回到文本入口。

## 5. 空间 A / B 与重启

- [ ] 在 A 有解析中的文件或未采用候选时切换至新建空间“文件夹验收 B”。应提示处理未保存工作；确认放弃并切换后，A 的候选、文件清单和迟到结果不能进入 B。
- [ ] B 中搜索 A 的独有知识、打开资料库，不能看到 A 的个人知识或资料。B 可以导入相同文件，不应被 A 的重复识别阻止。
- [ ] 在 A、B 各保存一个同名知识点，但设置不同描述、颜色和资料；切换后各自保持独立。修改一个空间不能改动另一个。
- [ ] 重命名 B，完全退出后用“准备”中的命令重新启动。应恢复最近空间；空间名称、各自知识、颜色、资料正文和来源关联应保留。

## 6. 扫描取消后的入口

- [ ] 选择一个包含较多文件或子目录的测试文件夹，在“正在查找文件…”时点击“取消”。若此样例扫描太快，可用自己另建的大测试目录；不要用正式知识库作为导入目标。
- [ ] 取消后立即可以再次“选择文件夹”或切换到“文本 / 单文件”，不应一直显示“正在选择…”或禁用入口。
- [ ] 立即选择另一个目录。应只出现新目录清单，旧扫描随后结束也不能覆盖新清单。已保存成果仍然保留。

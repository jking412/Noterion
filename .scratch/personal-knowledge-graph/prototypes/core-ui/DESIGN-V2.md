# 核心桌面体验原型：第二轮视觉候选

日期：2026-11-07（Asia/Shanghai）。

本轮回应用户对现有知识图谱视觉的明确否定，依据用户提供的两张参考图优化图谱及其周边界面。这是新的视觉候选，尚未获得用户认可；此前原型功能走查通过不代表视觉已获认可。方案选择及组合仍由 Issue #2 承接。

## 本轮可见设计选择

### 图谱画布

采用近白或很浅的冷灰连续画布，让知识点与所属关系成为主体。减少深色大面积底板、卡片边界和围绕图谱的装饰。搜索、画布、详情之间保留必要分隔；画布内部的工具集中放置，避免各处散落按钮或常驻说明。

### 节点、标签与主题

知识点用圆点表达，主题节点适当放大并配以主题图标；名称放在节点外，避免把每个知识点画成文字胶囊按钮。主题名称与当前选中名称优先清晰呈现，其他固定演示名称保持正常可读字号。

颜色按演示中的主题分簇使用，数量保持克制。颜色只帮助辨认所属结构，不新增熟悉程度、重要性或学习状态等语义。同名异义的“锁”继续通过所属主题、描述摘要与知识点身份区分。

共享“容器排障”在画布中只出现一个节点，以分别指向 Docker 和 Linux 运维的两条所属边表达共享，不为不同入口复制节点或描述。

### 关系与选中焦点

基础关系采用细灰线，降低未选中关系的视觉重量；当前节点相关线可加深。选中节点以明确外环、标签加深及邻接关系突出表达焦点。连线、箭头、圆点和文字应相互避让，箭头继续指向所属主题。

保持固定的 11 个演示知识点，不为模仿第二张参考图的密度而增加虚构节点、关系或类别。自然分布指当前真实演示关系的空间组织方式，不把图谱密度当作规模或性能证据。

### 画布操作

提供节点拖拽、画布平移、缩放和适应全图；工具使用清楚的图标、名称或可发现提示。搜索选择后突出并定位同一个知识点，详情同步显示完整描述与资料入口。选中一个节点不需要让其他节点持续无目的地运动。

图状态、删除入口及需要读取的业务事实应保持可达。模拟控制、版本、演示 ID 和完整状态等偶尔核查的信息放到可发现的展开区域，减少常驻辅助小字。

### 三方案的布局差异

- **A 图谱工作台**：简化搜索侧栏，减少重复标题、摘要和说明占据的空间，让浅色全图获得更大的连续区域；选中知识点的描述与资料仍在详情区访问。
- **B 检索工作台**：保留检索与结果比较优先的结构，结果表、局部图及右侧阅读区仍有明确分工；采用同一套新的图谱视觉与操作。
- **C 知识阅读台**：保留搜索弹窗、主题横栏、中央文档与所属主题图的阅读结构；完整描述仍是主位，图谱视觉与 A/B 一致。

三个方案不会因共用新的图谱视觉而合并为一个布局。它们继续用于比较搜索、图谱、描述和资料之间的主次。

## 保持的领域与原型边界

主题本身仍是知识点，知识点之间仍只采用“所属主题”。description 仍为知识点属性；文件与链接资料通过详情访问，不因视觉调整成为默认主图节点。共享身份、同名异义、编辑与删除规则保持既有定义。

保存成功与图更新状态仍分别表达；图不可用或尚未赶上时，不能把旧图伪装为最新，也不能把图查询故障呈现为无关联。搜索、描述与资料在已确认的故障边界内继续可用。

本轮仍是固定虚构数据、仅内存状态的可丢弃原型，不连接个人正式数据，不新增正式持久化、数据库、导入导出、备份、回收站或 AI 行为。实际画面、目标尺寸与主要操作的审核由当前执行 Agent 在实现后亲自完成，其结果另行记录。

## 发现、修正与复核

- 第一轮新图的 C 局部图中，横向缩放条会遮住当前知识点名称。改为画布右侧纵向工具，已在默认窗口和 1280×800 复核，名称与工具不重叠。
- A 的默认精简列表最初也隐藏了搜索摘要。改为搜索时恢复摘要，已实际确认 `docker exec` 的两条结果均显示名称与摘要。
- 搜索聚焦最初可能把小范围节点放得过大。限制自动聚焦比例上限，再次实际选择结果得到 125%，仍可手动缩放。
- 根据首轮实际画面加深节点名称与正文，增大同名“锁”的所属主题文字；简化常驻辅助文案。

这些是实际发现后修正的问题，不把“源码看起来正确”或“语法检查通过”作为画面通过的替代。

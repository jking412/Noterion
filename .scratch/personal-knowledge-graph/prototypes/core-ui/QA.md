# Issue #1 原型走查证据

走查日期：2026-11-07（Asia/Shanghai）。执行者在实际 Edge 页面完成操作与截图，不以源码检查代替页面验证。只验证原型行为，不验证正式应用或后端。

## 本次使用的技能与产物

- `prototype/SKILL.md` 与 `UI.md`：A/B/C 三个独立布局、同一路径的 `?variant=`、固定底部切换器、方向键、内存状态和一条命令入口。
- `frontend-design`：A 的全图工作台、B 的结果表与局部图、C 的文档阅读层级；按实际截图修正密度和字号。
- Sites：只发布固定演示资产到新建的本人私有站点；未接入数据库、个人资料或连接器。
- 并行 Agent 只读核对领域规则；画面与点击验收由当前执行 Agent 亲自完成。

## 发现并修正

- 最初 B 的结果区将局部图挤到首屏以下。改为固定检索区与独立滚动结果表，保留局部图和图中操作位置，已在 1280×800 复核。
- 最初 C 的搜索 SVG 缺少尺寸，撑高顶部。限定图标尺寸后重新查看 C，顶部恢复正常高度。
- A 的图节点文字在较窄桌面过小，增大图中文字与同名上下文标签；删除入口在深色背景中提高对比度，已复核。
- 切换知识点后原来的保存提示会延续到另一知识点；改为切换身份时清除该提示。最后一轮截图使用修正版本。
- 第一轮 JavaScript 语法检查发现图节点坐标变量与参数重名，在首次成功加载前修正，后续语法检查通过。

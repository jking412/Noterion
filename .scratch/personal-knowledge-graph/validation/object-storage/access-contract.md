## 稳定引用与凭据

本体引用至少包含 `connection_id + bucket + object_key`。资料名称与本体位置分开；原始文件名只用于展示，不承担对象唯一性。每次接收尝试分配唯一 key，持久记录预期大小、应用计算的 SHA-256、内容类型及操作身份；ETag 作为服务返回的不透明值保留，不能直接当作内容哈希。

`connection_id` 解析到已登记的固定存储位置及配置。修改“当前连接”不能让既有引用静默改指向另一服务；endpoint 的迁移或重新绑定需要独立处理。正式引用不包含 secret、签名 URL 或故障代理地址。

长期凭据由 Rust 连接层显式取得并传给 SDK，不静默采用开发机的默认云端凭据链。本次只使用随机生成的本机试验凭据，保存在忽略提交的 `.local/service.env`，经专用环境变量传入 Rust；不需要真实云账户。前端、正式资料记录、图投影及运行证据均不承载长期密钥；日志也不输出鉴权请求头、secret 或完整签名 URL。试验凭据的保管方式不构成最终桌面密钥保管方案已验收。

## 上传与读取子集

| 能力 | 调用方可依赖的行为 |
| --- | --- |
| 普通上传 | Rust 从文件流构造 `PutObject`；检查完整 SDK 结果，并核验对象大小与必要元信息。正式资料状态不能仅凭请求已发出变为就绪。 |
| 大文件分片 | 顺序采用 **8 MiB** 分片，末片使用剩余长度；逐片使用文件 `offset + Length::Exact` 流，不先把整文件装入内存。保存 upload ID、分片序号与 ETag；所有片传完仍须完成 multipart 并核验结果。此处不承诺自动断点续传。 |
| 完整读取 | 按稳定引用调用 `HeadObject`／流式 `GetObject`，提供大小、内容类型和可识别错误；上层按块消费，不经前端 IPC 一次传整文件 base64。 |
| 单区间读取 | 本次使用单个字节区间；返回精确字节、长度及 `Content-Range`，有效部分读取须符合 206 语义，越界区间须成为可识别的 416／`InvalidRange`。具体实测形式及样本范围以证据表为准。 |
| 临时只读入口 | Rust 按稳定引用即时生成短期 presigned GET，默认建议 5 分钟；返回有效期及请求必须保留的头。必要的 Range 与 URL 组合必须实际取回字节后采用。签名后不得修改 host，GET 签名不授予 PUT 权限。 |

签名 URL 是有时效的访问能力，不作为永久对象定位信息，也不写入可公开证据。对外提供临时入口仍应遵守资料访问权限；本次不扩展分享功能。

## 失败、未知结果与重新启动

接收状态至少在行为上区分进行中、未知、失败、已验证；字段名称由 #11 的实现确定。未完成 multipart、分片上传成功但未完成、取消、非法完成或结果未知均不得显示为本体就绪。`CompleteMultipartUpload` 必须检查完整 SDK 结果，HTTP 200 不能独立代表成功。

发送可能写入的请求前，持久保存本次操作的唯一 key 和预期内容标识。响应丢失、连接中断或超时可能发生在服务已经写入之后，记录保持未知，不据此断言“没保存”，也不盲目覆盖或删除对象。重新启动后，使用相同稳定引用进行只读 HEAD／GET 核验：核对大小、必要元信息及内容 SHA-256，匹配后才将本体转为已验证。未找到、拒绝访问、仍无法连接或内容不匹配继续保留可识别状态，不能伪装为已验证；单次 HEAD 未找到也不是已取消上传的证明。

对象访问错误至少向上层区分：

| 类别 | 调用方行为 |
| --- | --- |
| 未找到 | 明确报告目标对象不存在或尚不可读取，保留资料身份，不当作空文件 |
| 拒绝访问／签名失败 | 明确权限或认证错误，不当作未找到 |
| 非法范围 | 明确 Range 错误，由查看层修正请求 |
| 网络／超时 | 读取报告暂不可访问；写入保守保持未知，待核验 |
| 其他服务／协议错误 | 保留可识别的安全错误码和操作类型；不得仅按 HTTP 成功码吞掉响应体错误 |

## 与文件资料保存、视频查看的交接

#11 负责将已验证的本体与 PostgreSQL 正式资料记录衔接：只有本体验证成功且正式记录提交成功，才能显示“保存成功／可打开”。对象成功而 PostgreSQL 提交失败时，也须保留可核对的操作事实；本 Issue 不提供跨两者的原子事务保证。Neo4j 是可重建图查询表示，普通资料读取不依赖它；PostgreSQL 元信息和相应对象服务仍须可用。

删除知识点不自动删除资料对象。本次 multipart 取消只操作本次隔离试验的未完成会话，不引入资料自动删除、去重、对象版本或清理政策。查看缓存由稳定引用重新取得，始终是派生副本。
